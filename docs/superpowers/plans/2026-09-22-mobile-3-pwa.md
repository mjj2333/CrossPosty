# CrossPosty Mobile — Plan 3: Phone App (PWA) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A phone web app, installed to the iOS home screen, where the owner signs in once, composes a post with up to four images, picks Bluesky and/or X, schedules it or posts now, and sees a queue of scheduled, sent and failed posts.

**Architecture:** A Vite + React + Tailwind PWA in `app/` talking to Supabase directly with the user's session (RLS from Plan 1). It reuses the shared text code (`effectiveLength`, `splitIntoChain`, `formatForPlatform`) by relative import so counters and chain hints match the server. Images are compressed in the browser (canvas) before upload to the `post-media` bucket. "Post now" calls a new `post-now` Edge Function that claims one post and runs the same `processPost` the cron uses. Deployed to the existing Netlify site `crossposty-phone` (site id `4c30f4a2-de96-4ff0-8b51-7d8235a7f7a5`, https://crossposty-phone.netlify.app).

**Tech Stack:** Vite 6, React 18, TypeScript, Tailwind 3, `vite-plugin-pwa`, `@supabase/supabase-js@2`, Vitest (for two pure helpers), Netlify CLI (already logged in as the owner).

**Repo:** `C:\Users\drice\CrossPosty-mobile` (HEAD `8c8a52c`). Backend from Plans 1–2 is deployed and verified. Plan 4 (push notifications, storage cleanup, relay teardown) follows.

**Decisions made while planning:**
- No router library: four screens behind a bottom tab bar, state in React. YAGNI.
- Drafts live only in the `posts` table with `status = 'draft'`; no local persistence beyond the browser's own form state.
- X sign-in is not in the app (tokens come from `deno task authorize-x`); the Accounts screen shows the X account's status and says how to reconnect.
- Netlify env: the Vite build reads `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` from `app/.env.production`, written at deploy time from `.env.smoke` (gitignored; the anon key is public by design, but there's no reason to commit it).
- Supabase Auth email: the built-in sender is enough for one user. Magic links need the Site URL and Redirect URLs set in the dashboard (Task 7).

## Amendments from the Task 1–5 reviews

- **Sign-in is a 6-digit code, not a magic link.** An installed iOS home-screen app has its own storage; a magic link opens in Safari, where neither the PKCE verifier nor the resulting session is visible to the app. `SignIn` sends the OTP email, then verifies a typed code with `verifyOtp({ email, token, type: 'email' })`. **Dashboard:** the Magic Link email template must include `{{ .Token }}` or no code is sent (Task 8).
- Toolchain is Vite 8 / React 19 / TS 6 / vitest 5 (newer than the header says).
- `savePost` refuses to touch a row in `posting` (`.in('status', ['draft','scheduled','failed'])`) and preserves `sent` target results on edit; otherwise an edit during a send could re-post a target.
- Post-now path: `savePost` with `at = now + 2 min` so the cron cannot claim the row before `post-now` does (`claim_post` sets `scheduled_at = now()` anyway); treat a 409 from `post-now` as "already sending" and refresh the queue. Use an `AbortController` (~60 s) on the call; an abort means "still sending; check the queue".
- Compose: disable Schedule/Post now with zero targets (the DB check is the backstop); constrain the image picker to jpeg/png/webp/gif; keep draft state in `App` so switching tabs doesn't lose it; no Edit on `done` posts.
- `retryTarget` re-reads the row and returns a boolean; `deletePost` deletes the row before the objects.

```ts
// lib/cost.ts
// X pay-per-use: $0.015 per created post, $0.20 if the post contains a
// link. Each chunk of a thread is one post. Observed billing was lower
// (link surcharge not seen) — keep the estimate conservative.
const URL_RE = /https?:\/\/\S+/;
export const X_POST_USD = 0.015;
export const X_LINK_POST_USD = 0.2;

export function estimateXCost(text: string, chunks: number): number {
  const per = URL_RE.test(text) ? X_LINK_POST_USD : X_POST_USD;
  return Math.round(per * chunks * 1000) / 1000;
}

export function formatUsd(n: number): string {
  return n < 0.1 ? `$${n.toFixed(3)}` : `$${n.toFixed(2)}`;
}
```

```ts
// lib/time.ts
const pad = (n: number) => String(n).padStart(2, '0');

// <input type="datetime-local"> speaks local time without a zone.
export function toLocalInput(d: Date): string {
  return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}T${pad(d.getHours())}:${pad(d.getMinutes())}`;
}

export function fromLocalInput(s: string): Date {
  const [date, time] = s.split('T');
  const [y, m, d] = date.split('-').map(Number);
  const [hh, mm] = time.split(':').map(Number);
  return new Date(y, m - 1, d, hh, mm);
}

export function relative(iso: string, now = new Date()): string {
  const diff = new Date(iso).getTime() - now.getTime();
  const abs = Math.abs(diff);
  const unit = abs < 3_600_000 ? [60_000, 'min'] : abs < 86_400_000 ? [3_600_000, 'h'] : [86_400_000, 'd'];
  const n = Math.round(abs / (unit[0] as number));
  return diff >= 0 ? `in ${n} ${unit[1]}` : `${n} ${unit[1]} ago`;
}
```

```ts
// lib/compress.ts
// Bluesky rejects blobs over 2,000,000 bytes and phone photos are often
// 4–8 MB. Downscale the longest edge to 2048 px and re-encode as JPEG,
// lowering quality until under the target. Small files pass through.
const TARGET = 1_800_000;
const MAX_DIM = 2048;

export type PreparedImage = { blob: Blob; mimeType: string; width: number; height: number };

export async function prepareImage(file: File): Promise<PreparedImage> {
  const bitmap = await createImageBitmap(file);
  let { width, height } = bitmap;
  const needsResize = width > MAX_DIM || height > MAX_DIM;
  if (file.size <= TARGET && !needsResize && file.type !== 'image/heic') {
    bitmap.close();
    return { blob: file, mimeType: file.type, width, height };
  }
  if (needsResize) {
    const scale = MAX_DIM / Math.max(width, height);
    width = Math.round(width * scale);
    height = Math.round(height * scale);
  }
  const canvas = document.createElement('canvas');
  canvas.width = width;
  canvas.height = height;
  canvas.getContext('2d')!.drawImage(bitmap, 0, 0, width, height);
  bitmap.close();
  let quality = 0.85;
  let out: Blob | null = null;
  while (quality >= 0.4) {
    out = await new Promise<Blob | null>((r) => canvas.toBlob(r, 'image/jpeg', quality));
    if (out && out.size <= TARGET) break;
    quality -= 0.1;
  }
  if (!out) throw new Error('could not encode image');
  return { blob: out, mimeType: 'image/jpeg', width, height };
}
```

```ts
import { FUNCTIONS_URL, supabase } from './supabase';
import type { AccountView, MentionMap, Platform } from './types';

export async function listAccounts(): Promise<AccountView[]> {
  // Explicit columns: `secret` is not granted to the PWA and `*` would error.
  const { data, error } = await supabase
    .from('accounts')
    .select('platform, handle, status, updated_at')
    .order('platform');
  if (error) throw error;
  return (data ?? []) as AccountView[];
}

export async function connectBluesky(identifier: string, appPassword: string): Promise<string> {
  const { data: { session } } = await supabase.auth.getSession();
  if (!session) throw new Error('not signed in');
  const res = await fetch(`${FUNCTIONS_URL}/connect-bluesky`, {
    method: 'POST',
    headers: { authorization: `Bearer ${session.access_token}`, 'content-type': 'application/json' },
    body: JSON.stringify({ identifier, appPassword }),
  });
  const body = (await res.json()) as { handle?: string; error?: string };
  if (!res.ok) throw new Error(body.error ?? `HTTP ${res.status}`);
  return body.handle ?? identifier;
}

export async function disconnect(platform: Platform): Promise<void> {
  const { error } = await supabase.from('accounts').delete().eq('platform', platform);
  if (error) throw error;
}

export type Settings = { mention_map: MentionMap; default_targets: Platform[] };

export async function loadSettings(): Promise<Settings> {
  const { data, error } = await supabase.from('settings').select('mention_map, default_targets').maybeSingle();
  if (error) throw error;
  return (data as Settings | null) ?? { mention_map: [], default_targets: ['bluesky', 'x'] };
}

export async function saveSettings(patch: Partial<Settings>): Promise<void> {
  const { data: { user } } = await supabase.auth.getUser();
  if (!user) throw new Error('not signed in');
  const { error } = await supabase.from('settings').upsert({ user_id: user.id, ...patch });
  if (error) throw error;
}
```

```ts
// never a half-scheduled post.
export async function savePost(
  input: DraftInput,
  schedule: { at: Date } | null,
  existingId?: string,
): Promise<PostRow> {
  const uid = await userId();
  let id = existingId;
  if (!id) {
    const { data, error } = await supabase
      .from('posts')
      .insert({ user_id: uid, status: 'draft', text: input.text, variants: input.variants, targets: input.targets })
      .select('id')
      .single();
    if (error) throw error;
    id = data.id as string;
  }

  const media: MediaItem[] = [...input.keepMedia];
  for (let i = 0; i < input.images.length; i++) {
    const img = input.images[i];
    const storagePath = `${uid}/${id}/${Date.now()}-${i}`;
    const { error } = await supabase.storage.from('post-media').upload(storagePath, img.blob, {
      contentType: img.mimeType,
    });
    if (error) throw error;
    media.push({ storagePath, mimeType: img.mimeType, alt: img.alt });
  }

  const patch: Record<string, unknown> = {
    text: input.text,
    variants: input.variants,
    targets: input.targets,
    media,
    results: {},
  };
  if (schedule) {
    patch.status = 'scheduled';
    patch.scheduled_at = schedule.at.toISOString();
  } else {
    patch.status = 'draft';
  }
  const { data, error } = await supabase.from('posts').update(patch).eq('id', id).select('*').single();
  if (error) throw error;
  return data as PostRow;
}

export async function postNow(postId: string): Promise<{ status: string; results: PostRow['results'] }> {
  const { data: { session } } = await supabase.auth.getSession();
  if (!session) throw new Error('not signed in');
  const res = await fetch(`${FUNCTIONS_URL}/post-now`, {
    method: 'POST',
    headers: { authorization: `Bearer ${session.access_token}`, 'content-type': 'application/json' },
    body: JSON.stringify({ postId }),
  });
  const body = (await res.json()) as { status?: string; results?: PostRow['results']; error?: string };
  if (!res.ok) throw new Error(body.error ?? `HTTP ${res.status}`);
  return { status: body.status ?? 'failed', results: body.results ?? {} };
}

export async function listPosts(): Promise<PostRow[]> {
  const { data, error } = await supabase
    .from('posts')
    .select('*')
    .order('scheduled_at', { ascending: false, nullsFirst: true })
    .limit(200);
  if (error) throw error;
  return (data ?? []) as PostRow[];
}

// Only a scheduled post can be cancelled; one the job is sending stays put.
export async function cancelPost(id: string): Promise<boolean> {
  const { data, error } = await supabase
    .from('posts')
    .update({ status: 'draft', scheduled_at: null })
    .eq('id', id)
    .eq('status', 'scheduled')
    .select('id');
  if (error) throw error;
  return (data ?? []).length === 1;
}

export async function retryTarget(post: PostRow, platform: Platform): Promise<void> {
  const reset: TargetResult = { state: 'pending', attempts: 0 };
  const results = { ...post.results, [platform]: reset };
  const { error } = await supabase
    .from('posts')
    .update({ results, status: 'scheduled', scheduled_at: new Date().toISOString() })
    .eq('id', post.id)
    .eq('status', 'failed');
  if (error) throw error;
}

export async function deletePost(post: PostRow): Promise<void> {
  if (post.media.length > 0) {
    await supabase.storage.from('post-media').remove(post.media.map((m) => m.storagePath));
  }
  const { error } = await supabase.from('posts').delete().eq('id', post.id);
  if (error) throw error;
}

export function signedMediaUrl(path: string): Promise<string | null> {
  return supabase.storage
    .from('post-media')
    .createSignedUrl(path, 600)
    .then(({ data }) => data?.signedUrl ?? null);
}
```

```tsx
    })();

      const f = formatForPlatform(src, { platform: p, mentionMap });
      let chunks = 1;
      try {

      out[p] = { text: f.text, chunks, count: measure[p](f.text), unmapped: f.unmappedMentions };
    }
    return out;
  }, [text, variants, mentionMap]);

  const hints: Partial<Record<Platform, string>> = {};
  for (const p of targets) {
    const pv = preview[p]!;
    const chain = pv.chunks > 1 ? ` · ${pv.chunks} posts` : '';
    const cost = p === 'x' ? ` · ~${formatUsd(estimateXCost(pv.text, pv.chunks))}` : '';
    hints[p] = `${pv.count}/${CHAR_LIMIT[p]}${chain}${cost}`;
  }
  const unmapped = Array.from(new Set(targets.flatMap((p) => preview[p]?.unmapped ?? [])));

      setText('');
      setVariants({});
      setImages([]);
      if (mode === 'schedule') onDone();
    } catch (err) {
      setMessage(String(err));
    } finally {
      setBusy('idle');
    }
  }

  if (accounts.length === 0) {
    return <p className="text-gray-600">No accounts connected yet. Add one under Accounts.</p>;
  }

  return (
    <div className="space-y-4">
```

```tsx
        if (rows.length === 0) return null;
        return (
          <section key={g.title} className="space-y-2">
            <h2 className="font-semibold">{g.title}</h2>
            {rows.map((p) => (
              <PostCard
                key={p.id}
                post={p}
                onEdit={() => onEdit(p)}
                onCancel={() => act(async () => {
                  const ok = await cancelPost(p.id);
                  if (!ok) setError('Could not cancel: the post is already being sent.');
                })}
                onRetry={(platform: Platform) => act(() => retryTarget(p, platform))}
                onDelete={() => {
                  if (confirm('Delete this post?')) void act(() => deletePost(p));
                }}
              />
            ))}
          </section>
        );
      })}
      {posts.length === 0 && <p className="text-gray-600">Nothing yet. Compose something.</p>}
    </div>
  );
}
```

```tsx
            type="button"
            className="ml-auto bg-emerald-600 text-white rounded px-3 py-1"

      {msg && <p className="text-sm text-gray-700">{msg}</p>}
    </div>
  );
}
```
